# dsh-mimo-voice

给 DeepSeek Harness 用的本机发声插件：调小米 MiMo TTS 合成，落到 `audio/`，再用 `ffplay` 从本机音箱念出来。

- 聊天里自动念回复的第一句（可关）
- 卡在审批等你点确认时，念一句提醒（可关）
- 设置卡片里填密钥、调音色描述、试听、把满意的那条定为音色样本

## 装

```powershell
# 1. 让它对本机可见（profile 里指向这个目录）
pnpm --dir C:\Users\<你>\.dsh\profiles\desktop add link:D:/path/to/dsh-mimo-voice
# 2. 在 profile 的 package.json 里，把 dsh-mimo-voice 加进 dsh.profile.bundles
# 3. 重启桌面端
```

需要本机有 `ffplay` / `ffmpeg`。放在 `C:\ffmpeg\bin\`，或者设环境变量 `FFPLAY_PATH` / `FFMPEG_PATH`。

## 配

设置 → 插件 → dsh-mimo-voice（或「MiMo 声音」那一页）。页面按三块排：**① 声音 → ② 什么时候出声 → ③ 密钥**，改完点最下面「保存」才生效。右上角那个小标写着密钥填没填。

| 项 | 说明 |
| --- | --- |
| ① 音色描述 | 一句话描述声音，每次现造；点「试试这个声音」听，满意的点「就它了」转成克隆，声音就固定了 |
| ① 试听念什么 | 试听时念的文本 |
| ① 现在用的 | 显示当前是「定住的样本」还是「每次现造」；定住后可「切回现造」 |
| ② 提醒每轮出声 | 往系统提示词里放一段规则，让模型每回一条消息都挑一句交给 `speak`。**关了就不放**，`speak` 工具还在，只是没人提醒（见下节） |
| ② 要你确认时喊我 | 审批弹出来时念一句提醒 |
| ② 审批提醒说什么 | 一条一条往里加，列表里能逐条删；有几条就随机挑一条念。一条都没有就用出厂那句「任务需要权限，请审批。」。句首能加 `（语速快，很焦急）` 这类标签调语气 |
| ③ 密钥 | 小米 MiMo 的 key，存在插件根目录 `.env` 里 |

### 出声这件事怎么接上的

插件**不替人挑句子**。它只往系统提示词里塞一节，告诉模型：这机器接着音箱，每回一条消息都挑一句最要紧的交给 `speak`，语气写在 `text` 开头的括号里，正文不写记号。

设置页那个开关是**总闸**，管两件事：

- **提示词**：开着 → 每轮拼提示词时把这一节拼进去；关了 → 那一节返回空串，本轮提示词里没有它。
- **工具**：`speak` 的 `execute` 第一行就查这个开关，关着直接返回「出声关着，这次没念」，**不调 TTS**。

所以关掉以后不是「没人提醒但还能念」，是真的一点声音都出不来。关掉一般是因为这会儿不方便出声。

实现上走 `ctx.systemPrompt.section({ name, order: 3250, interpolate: false, text })`，`text` 传的是**函数**而不是字符串：每次拼提示词现读 `config.json` 的 `speakPrompt`，所以改开关**不用重启 DSH**。`interpolate: false` 是因为规则里有花括号，不能让提示词引擎去插值。**顺位压到最后（3250）**：这条规则得在生成之前还在眼前，排在前面会被后面几万字冲淡。

规则正文见 `lib/index.js` 的 `SPEAK_POLICY`。

### 括号里该怎么写字

按 MiMo 官方文档（`speech-synthesis-v2.5`）的音频标签规则来：标签贴在 assistant 正文最开头、紧挨第一个字，半角 `()`、全角 `（）`、方括号 `[]` 都认，多个风格塞同一对括号里。

关键是**只写正向、能演的动作**，不写否定式。「尾音不抬」「别叹气」「别拖长」这种，模型对「不」不敏感，有时会反着执行；要低就写「尾音收住往下落」，要慢就写「语速稍慢」。

优先用官方词表里的词，命中现成的比写散文稳：

- 整体语调：温柔 / 高冷 / 活泼 / 严肃 / 慵懒 / 俏皮 / 深沉 / 干练 / 凌厉
- 复合情绪：怅然 / 欣慰 / 无奈 / 愧疚 / 释然 / 嫉妒 / 厌倦 / 忐忑 / 动情
- 句中标签：气声 / 叹气 / 深呼吸 / 轻笑 / 冷笑 / 哽咽 / 颤抖 / 鼻音 / 不耐烦 / 心虚 / 撒娇 / 小声 / 提高音量喊话

**音色词（磁性 / 醇厚 / 清亮 / 空灵 / 稚嫩 / 苍老 / 甜美 / 沙哑 / 醇雅）别写进括号。** 音色已经由 `voiceDesign` 定死了，而 `voicedesign` 是每次调用现造一遍音色——括号里一旦出现音色词，那一次连底音都跟着重画，听着就像换了个人。这是这套设计唯一会「漂」的地方。

音色描述（`voiceDesign`）那一格本来就该吃掉长期设定——音色质感、语速、情绪底色，官方给的维度里就有「情绪/语气」和「语速/节奏」。所以括号只放这一句跟平时不一样的地方，别跟音色描述写成两条互斥的指令。要彻底钉死音色，走 `voiceMode: 'clone'`，给一段样本让它照着念。

`voicedesign` 不支持唱歌，也不支持预置音色与音色复刻（那是 `mimo-v2.5-tts` 的事）。

早期版本（≤0.3.0）是插件自己截 `assistant/message` 再挑句念的，带一整套 `pickLine` / `【念】` 记号规则；0.4.0 起整套拆掉，走上面的注入路线。

密钥以明文存在 `.env`（`MIMO_API_KEY=...`），`.env` 在 `.gitignore` 里，不会跟着源码走。
`config.json` 里没有密钥，可以正常提交；首次运行会自动生成，不存在也能跑。

## 路由

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/dsh-mimo-voice.config` | 读设置（密钥只回 `hasKey` 布尔） |
| POST | `/api/dsh-mimo-voice.config` | 写设置 |
| POST | `/api/dsh-mimo-voice.preview` | 试听，body 可带 `text` / `voiceDesign` |
| POST | `/api/dsh-mimo-voice.pin` | 把刚试的那条定为音色样本 |
| POST | `/api/dsh-mimo-voice.speak` | 念指定文本 |
| POST | `/api/dsh-mimo-voice.stop` | 掐掉正在放的那句 |

工具：`speak(text, wait?)`。

## 注意

- MiMo 的 voicedesign / voiceclone 每次按描述现造音色，结果不完全一样；想固定就用克隆。
- 这两个模型没有真流式，音频是一次性返回的，别指望边合成边播。
- TTS 限流 RPM 100，连发会 429，等几十秒。
